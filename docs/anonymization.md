# ЛР‑2 и курсовая работа

## Запуск

После установки по [основной инструкции](../README.md) запустите команду из корня проекта. Вывод содержит обезличенный текст и границы найденных фрагментов **в исходной строке**. Русские буквы и переводы строк входят в отсчёт. Для чтения файла в Windows программа сохраняет исходные CRLF.

```powershell
.\.venv\Scripts\python.exe -m pdn_lab anonymize --profile course --file examples/course.txt
.\.venv\Scripts\python.exe -m pdn_lab predict --profile course --file examples/course.txt
.\.venv\Scripts\python.exe -m pdn_lab anonymize --file examples/course.txt --spans-file spans.json
.\.venv\Scripts\python.exe -m pdn_lab anonymize --profile course --method mask --text "Иван получил кредит"
```

Создайте `spans.json` в UTF‑8 из результата `predict` для того же текста. Для вызова из Python доступны два интерфейса.

```python
from pdn_lab import anon, anonymize

text = "Иван получил кредит"
print(anon(text, [["NAME", 0, 4]]))  # ЛР-2, достаточно pip install -e .
new_text, source_spans = anonymize(text)  # КР, загружает модель и применяет профиль course
print(new_text, source_spans)
```

При пакетном вызове можно загрузить `Detector(NameModel.load(default_model_directory()), profile="course")` один раз и передавать его вторым аргументом в `anonymize`. Классы определены в `pdn_lab.detector` и `pdn_lab.model`. В CLI команда `predict` по умолчанию работает с восемью атрибутами ЛР‑1, `anonymize` — с их объединением с курсовым вариантом. Для отдельной проверки десяти атрибутов укажите `--profile course`.

## Что сохраняется при замене

| Метка | Правило |
|---|---|
| NAME, SURNAME | Разбор pymorphy3, выбор нового имени или фамилии из русского словаря Faker, склонение с учётом рода, числа и падежа. Сохраняются дефисы, инициалы и верхний регистр. |
| PATRONYMIC (ЛР) | Новое отчество согласуется по роду и склоняется. |
| EMAIL | Меняется локальная часть. Домен сохраняет исходное написание, включая регистр. |
| INN | Сохраняются длина и четыре первые цифры. Последнюю цифру для юрлица и две для физлица программа вычисляет заново. |
| PHONE (ЛР) | Сохраняются четыре первые цифры, скобки, пробелы и дефисы. Российские и международные номера проходят повторную проверку. |
| CARD | Сохраняются первые шесть цифр, последние четыре и разделители. Один внутренний разряд подбирается так, чтобы сумма Луна делилась на 10. |
| SNILS (ЛР) | Генерируются девять цифр основы и рассчитывается контрольное число. Сохраняются разделители. |
| PASSPORT | Сохраняются серия из четырёх цифр и исходные разделители. Меняется шестизначный номер. Слитные десять цифр требуют контекста паспорта. |
| OGRNIP | Сохраняются первые пять цифр, включая год и регион. Последняя цифра равна младшему десятичному разряду остатка от деления первых четырнадцати цифр на 13. |
| IP | Сохраняются версия адреса и сеть /24 для IPv4 или /64 для IPv6. Запись IPv6 выводится в канонической форме. |
| BIRTH_CERT | Сохраняются римская и буквенная части серии и разделители. Меняются шесть цифр номера. |
| KLADR | Новый код берётся из локального справочника на том же уровне адресной иерархии. Предпочтителен тот же регион. При единственном подходящем коде региона выбирается другой регион того же уровня. |

Внутри вызова повторное значение одного типа получает одну замену. Имя хранится в таблице в нормальной форме с признаком рода и склоняется для каждого употребления. Для структурированных номеров безразличны различия в разделителях, а формат каждого вхождения восстанавливается отдельно. Перед выбором программа резервирует исходные значения и исключает уже занятые замены того же класса. Неоднозначное имя согласуется с ближайшим сказуемым или соседним компонентом ФИО. Изолированное имя общего рода получает имя общего рода. Людей с одинаково написанными именами программа различает лишь в пределах доступных контекстных признаков.

В обычном режиме случайность обеспечивает `SystemRandom`, таблица соответствий живёт один вызов. Вероятность случайного совпадения двух запусков зависит от числа допустимых замен. Параметр Python `seed` фиксирует генерацию для воспроизводимого эксперимента. Недопустимые границы, пересечения, неизвестный тип и неверная контрольная сумма при явной разметке вызывают `ValueError`. Контрольная сумма проверяет структуру реквизита. Действительную выдачу номера человеку программа установить не может.

## КЛАДР

В поставку включён сжатый индекс из 911 451 числового кода открытого архивного снимка. Снимок содержит таблицы населённых пунктов, улиц и домов. Дата заголовка файла населённых пунктов — 09.04.2008, двух других файлов — 27.12.2006 (годы в заголовках сверяются с историей снимка). Поиск работает офлайн. Коды, добавленные позже и отсутствующие в снимке, такой индекс пропускает. [Архивный источник с фиксированной ревизией](https://github.com/maxlapshin/kladr/tree/9dd8a8deda91e51fd5cd8c874c0ec5c76059bd70/BASE)

Для обновления положите три файла `KLADR.DBF`, `STREET.DBF`, `DOMA.DBF` в один каталог и выполните `python scripts/build_kladr_catalog.py КАТАЛОГ src/pdn_lab/resources/kladr.txt.gz`. Номер версии справочника влияет на воспроизводимость результатов. [Страница ФНС о публикации КЛАДР](https://www.nalog.gov.ru/rn77/news/activities_fts/16629379/)

## Воспроизведение оценки КМ‑3

Выполните команды в PowerShell после установки готовых весов. Если в `data/processed` уже лежит базовый набор ЛР‑1, начните с подготовки курсового теста.

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[model,evaluation]"
.\.venv\Scripts\python.exe -m pdn_lab prepare
.\.venv\Scripts\python.exe scripts/prepare_course_test.py
.\.venv\Scripts\python.exe scripts/evaluate_course.py --device auto --output reports/course-v2.json
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider
```

При первом расчёте BERTScore загружается базовый RuBERT указанной в коде ревизии. Затем используется кэш. Первый диагностический набор можно восстановить флагом `--development`. Итоговый тест строится из других документов и шаблонов. Эталонные границы задаются аннотациями корпуса и при подстановке полей. Скрипт сохраняет SHA-256 набора и проверяет его перед оценкой.

В JSON приведены precision, recall и F1 по десяти атрибутам, средняя по атрибутам, weighted F1 по BIO, строгая F1 полных сущностей и результаты по источникам. Для BERTScore библиотека сравнивает оригиналы с двумя копиями, созданными по одним фактическим предсказаниям. При маскировании каждый символ найденного фрагмента превращается в звёздочку. Отдельно выводятся тексты, где было хотя бы одно изменение. Параметры `--seed` и `--device` позволяют повторить сравнение. BERTScore измеряет сходство текстов, а оставшиеся исходные фрагменты учитываются отдельно по разметке.
