# Готовая модель

Архив `rubert-pdn-v2.zip` в Release v3.0.0 предназначен для текущего кода распознавания v3. Он содержит веса и токенизатор для трёх компонентов ФИО; остальные пять атрибутов обрабатываются правилами проекта.

Базовая модель — [DeepPavlov/rubert-base-cased](https://huggingface.co/DeepPavlov/rubert-base-cased), ревизия `4036cab694767a299f2b9e6492909664d9414229`. Авторы исходного RuBERT: Yuri Kuratov и Mikhail Arkhipov; [публикация](https://arxiv.org/abs/1905.07213). Используется исходный регистрозависимый токенизатор.

Обучающая разметка включает компоненты ФИО из [factRuEval-2016](https://github.com/dialogue-evaluation/factRuEval-2016) и синтетические сложные примеры проекта. Для этой версии подготовлены 6574 train и 1286 validation текстов. Обновлялись все веса; лучшая эпоха выбрана по validation. Подробные параметры и хеши данных содержатся в `training_manifest.json` внутри архива.

Классы головы: `O`, `B/I-SURNAME`, `B/I-NAME`, `B/I-PATRONYMIC`. На выходе пользовательской программы возвращаются символьные границы после объединения с правилами.

Архив содержит только `config.json`, `model.safetensors`, `special_tokens_map.json`, `tokenizer.json`, `tokenizer_config.json`, `training_manifest.json`, `vocab.txt`. Локальные журналы, история экспериментов и отчёты проверки в него не входят. Адрес и SHA-256 зафиксированы в `models/release.json`.

Редкие имена, инициалы, составные фамилии с неверно предсказанным типом и неоднозначные контексты могут распознаваться неправильно. Модель не устанавливает личность человека и не подтверждает действительность найденных реквизитов. Исходные модель, корпус и библиотеки принадлежат их авторам; ссылки на источники сохранены для атрибуции.
